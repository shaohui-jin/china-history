## 背景

北宋中期，冗官、冗兵、冗费「三冗」问题积重难返。财政支出逐年膨胀，而税源有限。

熙宁元年，神宗即位，年二十，锐意求治。他问王安石：「卿所施设以何先？」

王安石答：「变风俗，立法度，最方今之所急也。」

## 经过

**制置三司条例司**

熙宁二年二月，神宗以王安石为参知政事，设制置三司条例司，以安石与陈升之同领。

《续资治通鉴长编》记：

> 熙宁二年二月，{以王安石为参知政事|任命王安石为参知政事}。安石曰：「{变风俗，立法度，最方今之所急也|改变风俗、建立法度，是当今最急迫的事}。」遂{设制置三司条例司|设立制置三司条例司}。{青苗、免役诸法次第行|青苗、免役等新法依次推行}，{而天下骚然|而天下骚动不安}。[^xuzizhitongjian-xining]

这是新法推行的中枢机构，直接绕过原有的三司（户部、度支、盐铁）。

**新法的内容**

| 法 | 内容 |
|---|---|
| 均输 | 调整各地贡物的运输与买卖，减少浪费 |
| 青苗 | 青黄不接时由政府低息贷款给农民 |
| 农田水利 | 兴修水利 |
| 免役 | 按户等出钱代役，官雇人服役 |
| 市易 | 政府参与市场买卖，平抑物价 |
| 方田均税 | 清丈土地，按实有田亩征税 |
| 保甲 | 十家为一保，维护治安、训练民兵 |
| 置将 | 改变「更戍法」，将领固定统兵 |
| 保马 | 民户养马，减免部分赋税 |

**设计的逻辑**

安石之设计，非无章法。其核心假设是：国家财力不足，非因税轻，而因「兼并之家」与「不耕之民」占据过多资源。

故理财之道在于重新分配，而非加赋。

- 青苗法以低息贷款取代高利贷
- 免役法以下户少出钱、上户多出钱而免役

**执行的落差**

然执行与设计之间，落差极大：

- 青苗钱在地方成为抑配指标，官吏强贷于民以求功
- 免役宽剩钱层层加码
- 市易务以官营挤压商贾

郑侠上《流民图》，王安石罢相（熙宁七年）。

**根本分歧**

新旧之争，不止于政策，更在于对「国家角色」的根本分歧：

| 立场 | 主张 |
|---|---|
| 王安石 | 国家可以主动塑造社会 |
| 司马光 | 「祖宗之法」与「民意」应当约束国家 |

此争在北宋未能解决。至南宋朱熹始有「元祐、熙宁互有得失」的持平论。

## 影响

**党争的开启**。元祐元年，司马光尽废新法。然党争未止，反愈演愈烈：绍圣绍述、崇宁党禁，直至靖康之变。

北宋亡于内耗与外患之交。

**「理财」观念的确立**。新法首次系统地把「理财」作为国家职能提出。此后的中国政治再也无法回避这一问题。

**「国家能力」的实验**。熙宁变法是中国历史上第一次大规模的「国家干预经济」实验。其失败的经验，被后世反复讨论。

**「王安石 vs 司马光」的范式**。这一对立成为此后中国政治思想的基本范式：改革与保守、效率与秩序、国家与社会。

## 争议

**新法失败的原因**。有「执行失败说」（政策本身可行但官吏腐败）、「设计缺陷说」（如青苗法强制摊派）、「利益冲突说」（触动大地主利益必然遭抵制）。

**王安石的历史评价**。南宋至清，主流评价为「祸国」。近代以来（梁启超《王安石传》）转为肯定。当代研究更倾向「政策有合理之处，执行有大问题」。

**「三冗」问题的根源**。有研究指出，北宋的财政困境本质上是「以募兵制替代府兵制」的结果——用钱买稳定，代价是财政不堪重负。新法未能触及这一根本。

前二事属归因与评价，第三事属制度分析，均无定论。
