## 待办

### U1 控件尺寸不统一

已修：9 处交互控件原先用了 4 种最小高度（`var(--touch-target)` / `2rem` / `1.875rem` / `32px`），
且都没有显式 `line-height`，继承正文的 1.75 后高度参差。

现在统一为三档令牌 `--control-sm|md|lg` + `--control-lh`，
并在 `.stylelintrc.mjs` 加了 `declaration-property-value-allowed-list` 强制拦截裸值。

**剩余**：视觉复核三个断点（375 / 768 / 1024+）。

### U2 时间线看不出先后

已修：事件原全部落在政权泳道同一条水平线上，密集处重叠。
现在泳道内按 x 距离做子分层错开，同一泳道的事件用浅色线串起来，
底部加了带箭头的主轴线与向下延伸的刻度线。

**剩余**：`layerStep` 与 `MIN_GAP` 两个常量是否合适，需在不同缩放下复核。

### U3 内容密度偏低

已补：事件从 117 增至 133 条，平均每世纪 4.3 条。
仍有 3 个世纪只有 1-2 条（前 1 世纪、18 世纪、19 世纪后半）。

**补充方向**：前 1 世纪（元成哀平已有、可补居摄与翟义起兵）、
18 世纪（雍正朝制度、准噶尔平定）、19 世纪（洋务运动、甲午、庚子后的新政）。

### P7 人物与事件关联

未出现在任何事件的人物：**23 / 319**。
没有任何参与者的事件：**10 / 133**。

剩余 23 人多为思想家、文学家、科学家（道安、慧远、陶渊明、王羲之、
韩愈、柳宗元、玄奘、刘勰、萧统、屈原等），在本书的事件体系里没有对应条目。
**不硬接**：往 `participants` 加人涉及「此人是否真的参与此事」的史实判断，
批量填充会制造错误（本仓库有过先例：认错王坚/王建）。

**验收**：不设人数目标。宁可留空，不造假关联。

## 不做清单

| 项目 | 原因 |
|---|---|
| `/sources/[id]` 详情页 | 单条史料内容量太小，独立成页价值低于维护成本 |
| 多主题切换（editorial / nocturne） | 已废弃，只保留 classical |
| Tailwind CSS | 已明确不用，原生 CSS + `@layer` |
| `places` 集合 / 地图 | 不在当前范围 |
| 图片 `srcset` / `loading="lazy"` | 全站零 `<img>` |
| 竖排文字 | 用户选择「稍后」 |
| webfont / 字体分片 | 已改用系统字体，首屏字体请求为 0 |
| 固定 Lighthouse 版本 | 字体不再是瓶颈，指标稳定 |
