## 背景

庆历年间，北宋面临双重危机：

**外患**。宋与西夏交战三年（1040–1042），三川口、好水川、定川寨三战皆败，最终以「赐岁币」换取和平。辽国也趁机索取，宋增输岁币。

**内忧**。冗官、冗兵、冗费「三冗」问题积重难返。官僚机构臃肿，恩荫入仕者众多，财政支出逐年膨胀。

庆历三年，仁宗问天下急务。范仲淹上《答手诏条陈十事》。

## 经过

**十事**

| 项 | 内容 |
|---|---|
| 明黜陟 | 改磨勘为按政绩升降 |
| 抑侥幸 | 限制恩荫入仕 |
| 精贡举 | 以策论取士取代诗赋 |
| 择官长 | 由中书与枢密选荐各路监司 |
| 均公田 | 给地方官公田，养廉 |
| 厚农桑 | 兴修水利，劝课农桑 |
| 修武备 | 整顿军备 |
| 减徭役 | 并省州县，减轻差役 |
| 覃恩信 | 落实朝廷恩泽 |
| 重命令 | 严守信令 |

其核心前五事，皆指向同一个目标：整顿官僚集团本身。

**推行与反弹**

《续资治通鉴长编》记：

> 庆历三年九月，范仲淹上十事。上嘉纳之，命仲淹、弼等分领其事。然「抑侥幸」一条，宗室、百官子弟皆怨。夏竦因诬仲淹等为朋党，事遂中变。[^xuzizhitongjian-qingli]

新政推行，欧阳修、余靖、蔡襄等为谏官，一时号「四谏」。

然「抑侥幸」直接削夺宗室、官僚子弟的世袭权益，反对声潮涌起。

夏竦指范仲淹、富弼、欧阳修为「朋党」。仁宗渐疑之——「朋党」是宋代政治中最敏感的词，因为它触及了皇权对士大夫结党的根本警惕。

**失败**

庆历五年，范仲淹罢参知政事，知邠州；富弼罢枢密副使，知郓州。

新政各项次第废止，前后不过一年余。

## 影响

**「朋党」问题的凸显**。庆历新政的失败，核心不在具体措施，而在「朋党」的指控。此后的熙宁变法、元祐更化，都反复陷入「朋党」之争。

**《岳阳楼记》的背景**。范仲淹《岳阳楼记》作于此时（庆历六年，贬邓州），末句：

> 先天下之忧而忧，后天下之乐而乐。

这非泛语，实为庆历党人自况。

**熙宁变法的先声**。二十余年后王安石变法，其「理财」「用人」两大主题，几乎全部承袭庆历之议，只是手段更激进。

**士大夫政治的成熟**。庆历新政是北宋士大夫第一次以群体形式参与国家治理的尝试。虽失败，但确立了「士大夫与天子共治天下」的政治理想。

## 争议

**失败的原因**。传统归咎于保守派反对。但也有研究指出，新政的许多措施（如「抑侥幸」）缺乏可操作性，且推行过急。

**「朋党」指控的性质**。有研究认为，范仲淹等人确实形成了一个政治集团，只是这个集团以「道义」为纽带，不同于后世的利益集团。欧阳修作《朋党论》，正是要为「君子之党」辩护。

**与熙宁变法的关系**。两者常被并称，但庆历新政侧重「吏治」，熙宁变法则侧重「理财」。这一差别反映了北宋士大夫对「问题根源」的认识变化。

前二事属归因与性质判断，第三事属变法史的连续性，均无定论。
